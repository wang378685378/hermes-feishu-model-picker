# 飞书后台配置自定义菜单

## 前置

- 已有一个飞书应用（App ID 以 `cli_` 开头）
- 已在应用里启用了「机器人」能力
- Hermes 的该 profile 已连接此飞书机器人

## 步骤

1. 打开 https://open.feishu.cn/app → 选择你的应用
2. 左侧菜单：**添加应用能力 → 机器人 → 添加能力**
3. 在机器人面板下方找 **机器人自定义菜单 → 编辑**
4. 打开「菜单状态」开关
5. 选择展示形式：
   - **可切换菜单**（推荐）：菜单和输入框占同一位置，用户点切换按钮
   - **悬浮菜单**：菜单浮在输入框上方
6. 默认展示：**菜单**
7. 添加菜单项（见下）

### 主菜单示例：按 provider 切换

每个菜单项：
- 名称：`🎯 <provider>`（≤ 60 字符，emoji 可选）
- 响应动作：**发送文字消息**
- 消息内容：`/model pick <provider>`

把 `<provider>` 换成你 `config.yaml` 里 `custom_providers[]` 的 provider 名。例如一个名为 `myprovider` 的 provider：

- 名称：`🎯 myprovider`
- 消息内容：`/model pick myprovider`

也可以只放一个「更换模型」项，内容填 `更换模型`，打开全部 provider 的汇总卡片。

### 可选：命令子菜单

- 名称：`🛠 命令`
- 子菜单（每项都是「发送文字消息」类型）：
  - `/compress` — 压缩上下文
  - `/retry` — 重试上一次
  - `/usage` — 查看用量
  - `/help` — 帮助

## 发布

- 保存菜单配置
- 进入 **版本管理** → **创建版本** → 发布
- 客户端 **等约 5 分钟** 才能看到新菜单

## 限制

- **只支持单聊**（群聊不显示菜单）
- **发送文字消息** 需要飞书客户端 **≥ 7.22**（旧版本菜单项会消失）
- 主菜单上限：可切换菜单 3 项 / 悬浮菜单 5 项
- 子菜单上限：可切换菜单 5 项 / 悬浮菜单 10 项
- 菜单名 ≤ 60 字符（长名字会截断）

## 每个 profile 独立

如果多个 Hermes profile 各绑定一个飞书机器人，每个机器人的菜单**都要单独在各自应用的后台配置**。一个应用的菜单配置**不会**自动应用到其他应用。
